# VIDEO AUTO CUTTER — ЕДИНЫЙ ПЛАН (WEB-APP ЛОКАЛЬНО)

## Контекст проекта

Проект: Video Auto Cutter
Тип: локальная веб-тулза для видеомонтажёров

Функции:

* нарезка видео по времени
* trimming по выбранному диапазону
* smart crop (vertical / horizontal)
* face detection (центрирование)

Стек:

* Python (FFmpeg, OpenCV)
* FastAPI (backend)
* React + Vite (frontend)

Формат запуска:

* пользователь клонирует репозиторий
* ставит зависимости
* запускает backend + frontend
* открывает в браузере (localhost)

Ограничения:

* полностью локально
* без облака
* без тяжёлых ML моделей
* стабильность важнее "магии"
